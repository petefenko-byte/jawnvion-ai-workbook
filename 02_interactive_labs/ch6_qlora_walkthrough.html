The Problem

Core Concept
LoRA — Low-Rank Decomposition

Instead of updating the full weight matrix W (d×d), LoRA injects two tiny matrices A (d×r) and B (r×d). Only A and B train. The rank r controls the parameter budget.

Architecture
QLoRA = Quantization + LoRA

QLoRA freezes the base model in 4-bit NF4 format (Normal Float 4), then adds trainable LoRA adapters in bf16. The quantized base never updates — only the adapters learn.

from transformers import AutoModelForCausalLM, BitsAndBytesConfig
import torch

# Configure 4-bit NF4 quantization
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_use_double_quant=True,   # nested quantization
    bnb_4bit_quant_type="nf4",           # Normal Float 4
    bnb_4bit_compute_dtype=torch.bfloat16
)

# Load model — weights land in 4-bit automatically
model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-2-7b-hf",
    quantization_config=bnb_config,
    device_map="auto"          # spread across available GPUs
)
# Model is now ~3.5 GB instead of 14 GB
from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training

# Prepare frozen layers for gradient checkpointing
model = prepare_model_for_kbit_training(model)

lora_config = LoraConfig(
    r=16,                  # rank — higher = more params, more expressiveness
    lora_alpha=32,          # scaling factor (usually 2×r)
    target_modules=[        # which weight matrices to adapt
        "q_proj", "k_proj",
        "v_proj", "o_proj",
        "gate_proj", "up_proj", "down_proj"
    ],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)

model = get_peft_model(model, lora_config)
model.print_trainable_parameters()
# trainable params: 6,553,600 || all params: 6,744,215,552 || trainable%: 0.0972
from transformers import TrainingArguments
from trl import SFTTrainer

training_args = TrainingArguments(
    output_dir="./qlora-output",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,   # effective batch = 16
    warmup_steps=100,
    learning_rate=2e-4,
    fp16=True,
    logging_steps=10,
    optim="paged_adamw_32bit",      # paged optimizer for large models
    save_strategy="epoch",
)

trainer = SFTTrainer(
    model=model,
    train_dataset=dataset,
    args=training_args,
    dataset_text_field="text",
    max_seq_length=2048,
)
trainer.train()
# Option 1: Save adapters only (~24 MB) for later merging
model.save_pretrained("./lora-adapters")

# Option 2: Merge adapters into full model for deployment
from peft import PeftModel

# Reload base in fp16 (not 4-bit) for clean merge
base = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-2-7b-hf",
    torch_dtype=torch.float16,
    device_map="auto"
)
merged = PeftModel.from_pretrained(base, "./lora-adapters")
merged = merged.merge_and_unload()   # fuse W' = W + α/r · BA
merged.save_pretrained("./merged-model")
# Ready to deploy as a standard HuggingFace model

Quick Reference
QLoRA Cheat Sheet
Key Hyperparameters
r = rank (4–64; start at 16)
lora_alpha = scaling (= 2×r)
lora_dropout = 0.05–0.1
lr = 2e-4 (higher than full FT)
epochs = 1–5 (task-dependent)
Quantization Types
NF4 — Normal Float 4 (best quality)
FP4 — Float Point 4 (simpler)
INT8 — for inference only (LLM.int8)
double_quant — quantize quant constants
compute_dtype — bf16 for training
Target Module Defaults
LLaMA: q,k,v,o,gate,up,down
Mistral: q,k,v,o,gate,up,down
Falcon: query_key_value
GPT-2: c_attn, c_proj
BERT: query, value
Key Equations
W' = W + α/r · B·A
B initialized: zeros
A initialized: gaussian noise
Params: 2·d·r per adapter
Merge at inference: merge_and_unload()
Optimizer Tips
paged_adamw_32bit — for large models
paged_adamw_8bit — saves another 4 GB
gradient_checkpointing — reduces VRAM
gradient_accumulation — simulate big batch
max_grad_norm=0.3 — clip gradients
Dataset Formats
SFT: {"text": "prompt + response"}
Chat: {"messages": [...]}
Instruction: alpaca-style JSON
Min examples: ~500–1000 for fine tasks
Quality > quantity: curate carefully
