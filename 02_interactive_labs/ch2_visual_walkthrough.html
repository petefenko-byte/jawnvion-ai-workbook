The Big Picture

You Can't Train a Model

A model learns by seeing thousands of examples. But raw examples are almost never clean — they have inconsistent formatting, missing values, irrelevant columns, and wildly different scales. Before a single weight gets updated, a data engineer has to load, inspect, clean, and understand the dataset.

That's what this chapter is about. These three tools are the foundation. You'll use them in every chapter after this.

Library 1 of 3

NumPy —
Fast Array Math

Python's built-in lists are flexible — but painfully slow for math. NumPy arrays store data in a single contiguous block of memory (like C or Fortran) and run operations in compiled machine code. When a neural network multiplies thousands of weight matrices together per second, it's doing it through NumPy — or its GPU cousin, PyTorch tensors.

Why this matters for LLMs

PyTorch tensors — the data type TinyLlama and every other LLM uses — are NumPy arrays with GPU support added on top. Every NumPy operation you learn here has a direct torch.Tensor equivalent. The concepts transfer 1:1.

Library 3 of 3 · Interactive

Matplotlib —
See What Your Data Says

Numbers in a table are hard to reason about. A chart makes the shape of your data immediately obvious — are answers normally distributed? Are there outliers? Is one category massively over-represented? Matplotlib turns DataFrames into plots in two lines of code. Below is the EDA (Exploratory Data Analysis) you'd run on any new dataset.

View:

What EDA tells you

→Are there outliers that'll confuse the model?
→Is one class massively over-represented?
→What's the typical token length? (affects context window)
→Are two features correlated — or independent?

Key Matplotlib functions

plt.hist() — distribution histogram
plt.scatter() — two-variable comparison
plt.plot() — loss curves (Ch3+)
plt.subplots() — 2×2 grid of charts
plt.savefig() — export to .png
plt.axvline() — mark the mean
