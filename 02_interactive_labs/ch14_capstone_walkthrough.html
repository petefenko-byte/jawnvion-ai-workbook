14.5 · When to Use What

Decision Trees

The three most common trade-off decisions every AI engineer faces.

❓ Do you have domain-specific proprietary data the base model has never seen?
YES →
Is the data primarily factual documents (manuals, policies, reports)?
YES →
✅ Use RAG — retrieval grounds the model in your docs without expensive retraining. Easier to update when docs change.
NO (stylistic, format, behavior changes needed) →
✅ Fine-tune (QLoRA) — adapt style, format, and domain vocabulary. Combine with RAG for the best of both.
NO →
Do you need better instruction-following or alignment to preferences?
YES →
✅ DPO / RLHF fine-tune — train on preference pairs. Chapter 7 patterns apply.
NO →
✅ Better prompting — system prompt engineering is free and often enough. Don't over-engineer.
❓ Is quality degradation below 2% perplexity increase acceptable?
MUST BE LOSSLESS →
✅ BF16 for training, FP16 for inference. No quantization.
YES, some loss OK →
Do you have a CUDA GPU for inference?
YES →
Do you need maximum INT4 quality?
YES →
✅ AWQ INT4 (best quality) or GPTQ INT4 (wide support). Deploy via vLLM.
EASE MATTERS MORE →
✅ bitsandbytes NF4 — one line of code, works in HuggingFace out of the box.
NO (CPU / local) →
✅ GGUF Q4_K_M via Ollama. Runs on MacBook or any CPU. Best portability.
❓ Does your use case handle regulated / government data (HIPAA, CUI, CMMC)?
YES →
✅ Self-hosted in isolated enclave (AWS GovCloud, Azure Government, on-prem). Data must never leave the boundary. CMMC Level 2+ compliance required.
NO →
Do you expect variable / unpredictable load?
YES →
✅ Modal / Replicate / Railway — serverless GPU, scale to zero. Chapter 10 Railway deploy pattern.
STEADY LOAD →
Need maximum throughput / lowest latency?
YES →
✅ Dedicated A100/H100 + vLLM with continuous batching. 50–100 req/s per GPU.
NO →
✅ HuggingFace Inference Endpoints or AWS SageMaker. Managed, no ops overhead.

# main.py — FastAPI application entry point (Ch 10 patterns)
from contextlib import asynccontextmanager
from fastapi import FastAPI, Depends, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel, Field

from model   import ModelSingleton, generate
from rag     import retrieve_context
from monitor import metrics, record_request
from security import guard_input, require_auth, rate_limit, audit, AuditEvent

# ── Lifespan: warm up model on startup ───────────────────
@asynccontextmanager
async def lifespan(app: FastAPI):
    ModelSingleton.load()          # INT4 model loaded once at startup
    yield
    ModelSingleton.unload()

app = FastAPI(title="EKOS Inference API", lifespan=lifespan)
app.add_middleware(CORSMiddleware, allow_origins=["*"], allow_methods=["*"])
app.mount("/metrics", metrics)

class ChatRequest(BaseModel):
    message: str = Field(..., min_length=1, max_length=4096)
    use_rag: bool = True
    max_tokens: int = Field(512, ge=1, le=2048)

class ChatResponse(BaseModel):
    reply: str
    sources: list[str]
    latency_ms: float
    tokens_used: int

@app.post("/chat", response_model=ChatResponse)
async def chat(
    body: ChatRequest,
    user_id: str = Depends(rate_limit),    # Ch 12: rate limiting
):
    import time
    t0 = time.perf_counter()

    # Ch 12: injection guard
    safe_msg = await guard_input(body.message)

    # Ch 8: RAG retrieval
    context, sources = await retrieve_context(safe_msg) if body.use_rag else ("", [])

    # Ch 4–7, 13: quantized model inference
    reply, tokens = await generate(safe_msg, context, max_tokens=body.max_tokens)

    latency = (time.perf_counter() - t0) * 1000

    # Ch 11: metrics + Ch 12: audit
    record_request(latency, tokens)
    audit(AuditEvent.PROMPT_SENT, user_id=user_id,
          tokens=tokens, latency_ms=round(latency, 1))

    return ChatResponse(reply=reply, sources=sources,
                          latency_ms=round(latency, 1), tokens_used=tokens)

@app.get("/health")
async def health(): return {"status": "ok", "model": ModelSingleton.name}
# rag.py — retrieval-augmented generation (Ch 8)
from langchain_community.vectorstores import PGVector
from langchain_openai import OpenAIEmbeddings
from langchain.retrievers import ContextualCompressionRetriever
from langchain.retrievers.document_compressors import CrossEncoderReranker
from langchain_community.cross_encoders import HuggingFaceCrossEncoder
from secrets import get_secret
import os

# ── Vector store (pgvector) ───────────────────────────────
CONN_STR = get_secret("/prod/db-url")

_store = PGVector(
    connection_string=CONN_STR,
    embedding_function=OpenAIEmbeddings(model="text-embedding-3-small"),
    collection_name="ekos_docs",
)

# ── Re-ranking retriever (MMR → cross-encoder) ────────────
_base_retriever = _store.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 8, "fetch_k": 30, "lambda_mult": 0.6},
)
_reranker = CrossEncoderReranker(
    model=HuggingFaceCrossEncoder(model_name="cross-encoder/ms-marco-MiniLM-L-6-v2"),
    top_n=4,
)
retriever = ContextualCompressionRetriever(
    base_compressor=_reranker, base_retriever=_base_retriever
)

async def retrieve_context(query: str) -> tuple[str, list[str]]:
    """Retrieve top-4 re-ranked chunks and their source citations."""
    docs = await retriever.ainvoke(query)
    context = "\n\n---\n\n".join(d.page_content for d in docs)
    sources = list({d.metadata.get("source", "unknown") for d in docs})
    return context, sources

# ── Ingest pipeline ───────────────────────────────────────
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.document_loaders import DirectoryLoader

def ingest_documents(doc_path: str):
    loader = DirectoryLoader(doc_path, glob="**/*.pdf")
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=800, chunk_overlap=120,
        separators=["\n\n", "\n", ". ", " "],
    )
    docs = splitter.split_documents(loader.load())
    _store.add_documents(docs)
    print(f"Ingested {len(docs)} chunks")
# model.py — quantized LLM singleton (Ch 13 + Ch 6)
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig
from peft import PeftModel

MODEL_BASE = "meta-llama/Meta-Llama-3-8B-Instruct"
LORA_PATH  = "./adapters/domain-lora"    # trained via QLoRA (Ch 6)

class ModelSingleton:
    model = None
    tokenizer = None
    name = None

    @classmethod
    def load(cls):
        if cls.model is not None: return

        # NF4 quantization config (Ch 13)
        bnb_cfg = BitsAndBytesConfig(
            load_in_4bit=True,
            bnb_4bit_quant_type="nf4",
            bnb_4bit_use_double_quant=True,
            bnb_4bit_compute_dtype=torch.bfloat16,
        )

        base = AutoModelForCausalLM.from_pretrained(
            MODEL_BASE, quantization_config=bnb_cfg,
            device_map="auto", torch_dtype=torch.bfloat16,
        )

        # Fuse domain-specific LoRA adapter (Ch 6)
        cls.model = PeftModel.from_pretrained(base, LORA_PATH)
        cls.tokenizer = AutoTokenizer.from_pretrained(MODEL_BASE)
        cls.name = "llama-3-8b-nf4+lora"

    @classmethod
    def unload(cls):
        import gc
        cls.model = cls.tokenizer = None
        gc.collect(); torch.cuda.empty_cache()

SYSTEM_PROMPT = """You are a precise technical assistant. Answer using only the
provided context. If the context is insufficient, say so explicitly.
Never invent facts."""

async def generate(message: str, context: str, max_tokens: int = 512) -> tuple[str, int]:
    prompt = f"""[SYSTEM] {SYSTEM_PROMPT}

[CONTEXT]
{context or "No retrieval context available."}

[USER] {message}
[ASSISTANT]"""

    enc = ModelSingleton.tokenizer(prompt, return_tensors="pt").to("cuda")
    with torch.inference_mode():
        out = ModelSingleton.model.generate(
            **enc, max_new_tokens=max_tokens,
            temperature=0.1, do_sample=True, repetition_penalty=1.1,
        )
    reply = ModelSingleton.tokenizer.decode(
        out[0][enc.input_ids.shape[1]:], skip_special_tokens=True
    )
    tokens_used = out.shape[1] - enc.input_ids.shape[1]
    return reply.strip(), tokens_used
# monitor.py — Prometheus metrics + drift detection (Ch 11)
from prometheus_client import Counter, Histogram, Gauge, make_asgi_app
from apscheduler.schedulers.asyncio import AsyncIOScheduler
import numpy as np

# ── Prometheus metrics ────────────────────────────────────
REQUEST_COUNT   = Counter("llm_requests_total", "Total inference requests", ["status"])
LATENCY         = Histogram("llm_latency_ms", "Request latency (ms)",
                              buckets=[50,100,200,500,1000,2000,5000])
TOKENS_USED     = Counter("llm_tokens_total", "Total tokens generated")
CONFIDENCE_LAST = Gauge("llm_confidence_last", "Last response confidence score")
PSI_GAUGE       = Gauge("llm_psi_score", "Population Stability Index")

metrics = make_asgi_app()   # mount at /metrics for Prometheus scrape

def record_request(latency_ms: float, tokens: int, status: str = "ok"):
    REQUEST_COUNT.labels(status=status).inc()
    LATENCY.observe(latency_ms)
    TOKENS_USED.inc(tokens)

# ── PSI drift detection ───────────────────────────────────
def compute_psi(reference: np.ndarray, current: np.ndarray, bins: int = 20) -> float:
    """Population Stability Index — <0.1 stable, 0.1-0.25 caution, >0.25 retrain"""
    eps = 1e-8
    ref_counts, edges = np.histogram(reference, bins=bins, range=(0,1))
    cur_counts, _    = np.histogram(current,   bins=edges)
    ref_pct = ref_counts / (ref_counts.sum() + eps)
    cur_pct = cur_counts / (cur_counts.sum() + eps)
    psi = np.sum((cur_pct - ref_pct) * np.log((cur_pct + eps) / (ref_pct + eps)))
    return float(psi)

# ── Scheduled drift check (every 4 hours) ────────────────
scheduler = AsyncIOScheduler()
confidence_buffer: list[float] = []
reference_dist = np.load("./data/reference_confidence.npy", allow_pickle=True)

@scheduler.scheduled_job("interval", hours=4)
async def drift_check():
    if len(confidence_buffer) < 100: return
    psi = compute_psi(np.array(reference_dist), np.array(confidence_buffer[-500:]))
    PSI_GAUGE.set(psi)
    if psi > 0.25:
        await trigger_retrain_pipeline(reason=f"PSI={psi:.3f} exceeds threshold")

async def trigger_retrain_pipeline(reason: str):
    import httpx
    await httpx.AsyncClient().post(
        "https://ci.example.com/trigger/retrain",
        json={"reason": reason, "model": "llama-3-8b"},
        headers={"Authorization": f"Bearer {get_secret('/ci/token')}"},
    )

14.7 · The Road Ahead

What's Next in AI Engineering

The field moves fast. These are the techniques reshaping production AI right now.

🎭

Mixture of Experts (MoE)

Route tokens to specialized sub-networks. Mixtral 8×7B delivers 70B-class quality at 13B inference cost. MoE fine-tuning is the next frontier.

Active now
📏

Long Context Models

Context windows hitting 1M+ tokens. Gemini 1.5, Claude, and Llama 3.1 128K make whole-codebase and whole-manual reasoning practical.

Active now
🔄

State Space Models (Mamba)

Linear-time sequence modeling — no quadratic attention cost. Promising for long-sequence inference. Still maturing but watch this space.

Emerging
🤖

Agentic Loops

LLMs that plan, use tools, browse, write code, and self-correct over many steps. LangGraph, CrewAI, and AutoGen are the main frameworks.

Active now
👁️

Multimodal Models

GPT-4o, Llava, and Phi-3 Vision handle image + text natively. Audio, video, and structured data modalities are next.

Active now
🧬

Speculative Decoding

Draft tokens with a small model, verify with a large one. 2–3× throughput gains with identical output quality. Already in vLLM and TGI.

Active now
