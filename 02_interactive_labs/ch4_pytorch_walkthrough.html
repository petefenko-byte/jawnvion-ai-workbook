Section 04

Your First Neural Network in PyTorch

Every PyTorch model inherits from nn.Module. You define the layers in __init__ and the forward computation in forward().

Input Layer
784 neurons
Hidden Layer 1
256 neurons + ReLU
Hidden Layer 2
128 neurons + ReLU
Output Layer
10 classes
import torch.nn as nn class SimpleNet(nn.Module): def __init__(self): super().__init__() self.layers = nn.Sequential( nn.Linear(784, 256), # input → hidden1 nn.ReLU(), nn.Linear(256, 128), # hidden1 → hidden2 nn.ReLU(), nn.Linear(128, 10), # hidden2 → output ) def forward(self, x): return self.layers(x) model = SimpleNet().to(device) print(model) # prints architecture print(sum(p.numel() for p in model.parameters())) # ~235k params

Section 05

The Training Loop

Every PyTorch training loop follows the same five-step pattern. Get it wrong and gradients accumulate — or never flow at all.

1
Forward Pass
Run the input through the model to get predictions.
predictions = model(inputs)
2
Compute Loss
Measure how wrong the predictions are vs. ground truth.
loss = criterion(predictions, targets)
3
Zero Gradients
Clear gradients from the previous step — they accumulate by default.
optimizer.zero_grad()
4
Backward Pass
Autograd computes gradients for every parameter.
loss.backward()
5
Update Weights
The optimizer nudges every parameter in the direction that reduces loss.
optimizer.step()
