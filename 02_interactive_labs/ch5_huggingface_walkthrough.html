Section 02

Tokenization: Text → Numbers

Models don't see words. They see integers. A tokenizer splits your text into sub-word pieces (BPE), maps each piece to an ID, and hands the ID sequence to the model.

Why BPE?
Byte-Pair Encoding starts with individual characters and merges the most frequent pairs repeatedly. "unbelievable" might tokenize as ["un","believ","able"] — three tokens, not twelve. This lets a 32K-token vocabulary cover any text efficiently, including code and non-English languages.
Special Tokens
# TinyLlama uses Llama's chat template BOS = "<s>" # start of sequence EOS = "</s>" # end of sequence SYS = "<<SYS>>" # system prompt INST= "[INST]" # user turn PAD = "<unk>" # padding token

HuggingFace Cheat Sheet

🔌
Load Any Model
Auto-classes infer the right model class from the Hub config.
from transformers import AutoTokenizer, AutoModelForCausalLM

tok = AutoTokenizer.from_pretrained("model-id")
model = AutoModelForCausalLM.from_pretrained(
    "model-id",
    torch_dtype=torch.float16,
    device_map="auto"
)
🚰
Quick Inference with pipeline()
One-liner for simple inference tasks.
from transformers import pipeline

pipe = pipeline(
    "text-generation",
    model="TinyLlama/TinyLlama-1.1B-Chat-v1.0",
    torch_dtype=torch.float16,
    device_map="auto"
)
out = pipe("Tell me about LLMs", max_new_tokens=100)
💬
Chat Template
TinyLlama-Chat expects a specific prompt format.
messages = [
    {"role": "system", "content": "You are a helpful AI."},
    {"role": "user", "content": "What is fine-tuning?"}
]
prompt = tok.apply_chat_template(
    messages, tokenize=False, add_generation_prompt=True
)
💾
Save & Load Locally
Cache models to avoid re-downloading.
model.save_pretrained("./tinyllama-local")
tok.save_pretrained("./tinyllama-local")

# Load from local path
model = AutoModelForCausalLM.from_pretrained("./tinyllama-local")
🔍
Inspect the Model
Count parameters, check architecture.
print(model.config)
print(model.config.num_hidden_layers)  # 22
print(model.config.hidden_size)        # 2048

total = sum(p.numel() for p in model.parameters())
print(f"{total:,}")  # 1,100,048,640
