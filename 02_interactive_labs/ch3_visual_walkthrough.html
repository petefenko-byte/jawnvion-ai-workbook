The Structure

The Multi-Layer
Perceptron (MLP)

A neural network is a stack of mathematical layers. Each layer takes a vector of numbers, multiplies it by a matrix of learned weights, adds a bias vector, then passes the result through a nonlinear activation function. Stack two or more of these and you get an MLP — the building block behind every modern AI system.

Weights & Biases

W and b are the parameters the network learns. Randomly initialized, then iteratively nudged toward values that minimize loss. A 3→4→1 MLP has 3×4 + 4 + 4×1 + 1 = 21 parameters.

⚡

Why Nonlinearity?

Without activation functions, stacking layers collapses to a single linear transformation — no matter how deep the network. ReLU breaks this and lets the network learn curved decision boundaries.

🎯

Universal Approximator

A 2-layer MLP with enough hidden neurons can approximate any continuous function. This is the Universal Approximation Theorem — the theoretical foundation for all of deep learning.

Numbers Flow Left to Right

The forward pass is just arithmetic. Feed an input vector, multiply by each weight matrix, add the bias, apply the activation — and you get a prediction. Every single token TinyLlama generates goes through millions of these operations in milliseconds.

The Nonlinearity

Activation Functions —
The Hinge of Deep Learning

Without a nonlinear function between layers, any depth of network collapses to a single matrix multiply. Activation functions introduce the curves that let a network model real-world complexity. Three matter most — and you need to know when to use each.

ReLU(x)
f(x) = max(0, x)
Used in hidden layers. Simple, no vanishing gradient for positive inputs. When x < 0, output is 0 ("dead neuron").
Sigmoid(x)
f(x) = 1 / (1 + e−x)
Squashes input to (0,1). Used at the output layer for binary classification. Suffers vanishing gradients in deep networks.
Tanh(x)
f(x) = (ex − e−x) / (ex + e−x)
Zero-centered version of Sigmoid. Output range (−1, 1). Often preferred over Sigmoid in hidden layers when symmetry matters.
When to use which?
Hidden layers: ReLU (default)
Binary output: Sigmoid
Multi-class output: Softmax
RNNs / attention: Tanh
How Learning Happens

Backpropagation —
Gradients Flow Backwards

After a forward pass produces a prediction, we compute the loss. Then backpropagation asks: how much did each weight contribute to that loss? Using the chain rule from calculus, it computes a gradient for every parameter in the network — in one backward sweep. Those gradients tell gradient descent exactly which direction to nudge each weight.

The Chain Rule
dL/dW₂ = dL/dŷ × dŷ/dz₂ × dz₂/dW₂
Loss gradient flows backward through every operation that produced it — chain-multiplying derivatives at each step.
W₂ ← W₂ − lr × dL/dW₂

Backprop in 4 steps

1 Compute loss: L = BCE(ŷ, y)
2 Gradient at output: dL/dŷ
3 Chain rule backward through each layer
4 Update: W -= lr × dL/dW

The deep learning insight: Because every operation in a neural network is differentiable, backprop is fully automatic. This is why PyTorch has autograd — it tracks every operation and computes all gradients in one backward pass. In Chapter 3, you implement this by hand so the abstraction becomes concrete.

The NumPy training loop

for epoch in range(100):
# forward
z1 = W1 @ X.T + b1
h1 = relu(z1)
y_hat = sigmoid(W2 @ h1 + b2)
# loss + backward
loss = bce(y_hat, y)
dW1, dW2, ... = backward(...)
# update weights
W1 -= lr * dW1
W2 -= lr * dW2

What you will see in the notebook

→Loss drops fast early, then slows (diminishing returns)
→Accuracy climbs from ~52% to ~94% over 100 epochs
→Learning rate too high → loss oscillates or explodes
→Dead neurons stay dead unless you reinitialize weights
