Why FastAPI

The Right Tool for ML Serving

Flask is fine for demos. FastAPI is built for production — async, typed, and self-documenting out of the box.

⚡ Async by Default

ASGI-native. While one request waits for model inference, the event loop serves others. No threads, no GIL fights — crucial for latency under load.

🔒 Pydantic Validation

Define your request schema once. FastAPI validates inputs, coerces types, and returns a structured 422 with field-level errors — before your model ever runs.

📚 Auto-Docs Free

OpenAPI schema and interactive Swagger UI at /docs, Redoc at /redoc — generated from your type annotations, zero extra work.

🚀 Performance

Benchmarks show FastAPI close to Node.js and Go for I/O-bound workloads. Starlette underneath, uvicorn on top — a serious production stack.

🧩 Dependency Injection

Inject model instances, DB connections, auth handlers via Depends(). Composable, testable, and mockable — the pattern that makes large APIs maintainable.

🧪 Testable

Built-in TestClient wraps requests in-process. Write unit tests that hit your real routes without spinning up a server — CI-ready from day one.

Architecture

Model Loading Patterns

How you load your model matters more than almost any other architectural decision. These three patterns have very different latency, memory, and concurrency profiles.

from contextlib import asynccontextmanager
from fastapi import FastAPI
from transformers import pipeline

# Global model registry
model_cache: dict = {}

@asynccontextmanager
async def lifespan(app: FastAPI):
    # Load ONCE at startup
    model_cache["clf"] = pipeline(
        "text-classification",
        model="distilbert-base-uncased-finetuned-sst-2-english",
        device=0  # GPU if available
    )
    yield
    # Cleanup on shutdown
    model_cache.clear()

app = FastAPI(lifespan=lifespan)

@app.post("/predict")
async def predict(req: PredictRequest):
    # Reuse the loaded model — no reload
    result = model_cache["clf"](req.text)
    return result

from fastapi import FastAPI, Depends
from functools import lru_cache
from transformers import pipeline

@lru_cache(maxsize=4)
def get_model(model_id: str):
    # Cached by model_id — first call loads,
    # subsequent calls return cached instance
    return pipeline(
        "text-classification", model=model_id
    )

async def model_dependency(
    model_id: str = "distilbert-base"
):
    return get_model(model_id)

app = FastAPI()

@app.post("/predict")
async def predict(
    req: PredictRequest,
    model = Depends(model_dependency)
):
    # Model injected — cached after first call
    result = model(req.text)
    return result

from fastapi import FastAPI
from transformers import pipeline

app = FastAPI()

@app.post("/predict")
async def predict(req: PredictRequest):
    # Load model on EVERY request — ❌ avoid in production
    model = pipeline(
        "text-classification",
        model=req.model_id
    )
    result = model(req.text)

    # Model goes out of scope and is GC'd after
    return result

# This pattern is only acceptable when:
# - You're in a serverless function with forced cold starts
# - Models are tiny (<10MB) and load in <50ms
# - You have a strict per-request isolation requirement

Complete Implementation

Production-Ready Code

A full FastAPI ML service — schemas, lifespan loading, health checks, middleware, and deployment config.

from contextlib import asynccontextmanager
from fastapi import FastAPI, HTTPException, BackgroundTasks
from fastapi.middleware.cors import CORSMiddleware
from transformers import pipeline
import time, logging

from schemas import PredictRequest, PredictResponse, HealthResponse

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

# ── Model registry ───────────────────────────────
models: dict = {}

@asynccontextmanager
async def lifespan(app: FastAPI):
    logger.info("Loading model…")
    models["clf"] = pipeline(
        "text-classification",
        model="distilbert-base-uncased-finetuned-sst-2-english",
        truncation=True, max_length=512
    )
    logger.info("Model ready ✓")
    yield
    models.clear()

# ── App ──────────────────────────────────────────
app = FastAPI(
    title="EKOS Inference API",
    version="1.0.0",
    lifespan=lifespan
)
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["POST", "GET"],
    allow_headers=["*"],
)

# ── Routes ───────────────────────────────────────
@app.get("/health", response_model=HealthResponse)
async def health():
    return {
        "status": "ok",
        "model_loaded": "clf" in models,
        "version": app.version
    }

@app.post("/predict", response_model=PredictResponse)
async def predict(req: PredictRequest,
                   bg: BackgroundTasks):
    if "clf" not in models:
        raise HTTPException(503, "Model not loaded")
    t0 = time.perf_counter()
    out = models["clf"](
        req.text,
        return_all_scores=req.return_probs
    )
    latency_ms = round((time.perf_counter() - t0) * 1000, 2)
    bg.add_task(logger.info, f"Inference: {latency_ms}ms")
    return {
        "label": out[0]["label"] if not req.return_probs else None,
        "score": out[0]["score"] if not req.return_probs else None,
        "all_scores": out[0] if req.return_probs else None,
        "latency_ms": latency_ms
    }

from pydantic import BaseModel, Field, field_validator
from typing import Optional, List

# ── Request ───────────────────────────────────────
class PredictRequest(BaseModel):
    text: str = Field(
        ...,
        min_length=1,
        max_length=10000,
        description="Input text to classify"
    )
    model_id: str = Field(
        "distilbert-base-sentiment",
        description="Model identifier"
    )
    max_length: int = Field(128, ge=1, le=512)
    return_probs: bool = Field(False)

    @field_validator("text")
    @classmethod
    def strip_whitespace(cls, v: str) -> str:
        stripped = v.strip()
        if not stripped:
            raise ValueError("text must not be blank")
        return stripped

# ── Response ──────────────────────────────────────
class PredictResponse(BaseModel):
    label: Optional[str]    # "POSITIVE" / "NEGATIVE"
    score: Optional[float]  # confidence 0–1
    all_scores: Optional[List[dict]]  # when return_probs=True
    latency_ms: float

class HealthResponse(BaseModel):
    status: str
    model_loaded: bool
    version: str

# Pydantic generates OpenAPI schema from these
# → FastAPI serves it at /openapi.json + /docs

import time
from fastapi import Request
from starlette.middleware.base import BaseHTTPMiddleware

# ── Latency logging middleware ─────────────────────
class TimingMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        t0 = time.perf_counter()
        response = await call_next(request)
        ms = round((time.perf_counter() - t0) * 1000, 2)
        response.headers["X-Process-Time-Ms"] = str(ms)
        return response

# ── Rate limiting (simple in-memory) ──────────────
from collections import defaultdict
from fastapi import HTTPException

request_counts: dict = defaultdict(list)

class RateLimitMiddleware(BaseHTTPMiddleware):
    def __init__(self, app, max_req: int = 60, window: int = 60):
        super().__init__(app)
        self.max_req, self.window = max_req, window

    async def dispatch(self, request: Request, call_next):
        ip = request.client.host
        now = time.time()
        calls = [t for t in request_counts[ip] if now - t < self.window]
        if len(calls) >= self.max_req:
            raise HTTPException(429, "Rate limit exceeded")
        calls.append(now)
        request_counts[ip] = calls
        return await call_next(request)

# Register both on the app:
app.add_middleware(TimingMiddleware)
app.add_middleware(RateLimitMiddleware, max_req=60)

Where to Deploy

Deployment Platforms Compared

From zero to production — pick the right platform for your scale, budget, and GPU requirements.

🚄 Railway

Push-to-deploy from GitHub. Dockerfile support, persistent volumes, custom domains. Best for CPU inference at small-to-medium scale. Free tier available.

Free tier Dockerfile CPU only ~$5–20/mo

⚡ Modal

Serverless GPU inference with cold start mitigation via keep_warm. Pay per second of compute. Ideal for burst workloads or GPU-required models.

GPU T4/A100 Pay-per-use Keep-warm No idle cost

☁️ AWS ECS / Fargate

Fully managed containers. Fargate = serverless; ECS on EC2 = persistent GPU (g4dn.xlarge). Best for compliance-sensitive or high-volume production workloads.

GPU EC2 Auto-scaling Complex setup $50–500+/mo

🤗 HuggingFace Spaces

Zero-config deploy directly from a HF repo. A100 GPU Spaces available. Great for demos, open-source models, and community-facing apps with built-in auth.

Free CPU tier GPU Spaces HF ecosystem $0–$20/mo
Quick Reference

FastAPI ML Cheat Sheet

Essential Files

›main.py — FastAPI app + routes
›schemas.py — Pydantic request/response models
›Dockerfile — container spec
›requirements.txt — pinned deps
›.env — secrets (never in image)

Model Loading Rules

›Always load in lifespan(), not at module level
›Use global dict or @lru_cache — never per-request
›Move model to GPU in lifespan, not in handler
›Set start_period in health check ≥ load time

Pydantic Patterns

›Use Field(ge=0, le=512) for numeric bounds
›Validators strip and normalize before hitting model
›Return 422 automatically on type/validation errors
›response_model= filters and validates output too

Performance Tips

›Use --workers 2 for CPU; 1 per GPU for GPU
›Batch requests with a queue (e.g. Celery + Redis)
›torch.no_grad() in inference — saves 30–40% memory
›Cache model outputs for repeated identical inputs

Docker Best Practices

›requirements.txt before source code for layer caching
›Non-root USER in final image — security requirement
›python:3.11-slim not full — saves ~600MB
›Mount HF cache as volume — avoid re-downloading

Key URLs (local dev)

›/docs — Swagger UI, try endpoints
›/redoc — ReDoc reference docs
›/openapi.json — raw OpenAPI schema
›/health — load balancer probe target
