12.1 · Threat Landscape

Why LLM Security Is Different

LLMs introduce unique attack surfaces that traditional AppSec doesn't cover. The model is part of the attack surface.

💉

Prompt Injection

Adversarial input hijacks the model's instructions. The model can't distinguish its system prompt from user-supplied data that mimics it.

🔓

Data Exfiltration

Training data, system prompts, or in-context secrets can be extracted by adversarial queries. RAG pipelines add retrieval as another exfil vector.

⛓️

Supply Chain Attacks

Poisoned datasets, malicious model weights, and compromised dependencies can embed backdoors that are invisible until triggered.

Resource Server (LLM API)

Best for machine-to-machine. The access token has a short TTL (1–15 min). On expiry the service fetches a new one — no user interaction needed. Scopes restrict what the token can do: llm:inference llm:embeddings.

Limitations

  • Token refresh overhead

Secrets Hygiene Ladder

🔴
Never: Hardcode in Source
OPENAI_KEY = "sk-abc123" — shows in git log forever, even after deletion
🟡
Acceptable: Environment Variables
os.environ["OPENAI_KEY"] — safe if .env is gitignored and rotated regularly
🟢

⭐
Ideal: Dynamic Short-Lived Credentials
IAM role + STS AssumeRole. No static secret exists. TTL: 15 min. Auto-rotated by AWS.
12.5 · Supply Chain Security

Model Provenance & Dependency Hygiene

Every dependency and model weight is an attack surface. Treat them like production code.

🏷️ Model Provenance

Verify SHA-256 of every model checkpoint. Only pull from official registries (HuggingFace, PyTorch Hub). Reject unsigned or community-only weights in production.

📦 Dependency Scanning

Run pip-audit and safety in CI. Pin to exact versions with a lock file. Alert on transitive vulnerabilities in deep deps like transformers.

# injection_guard.py — prompt injection detection layer
import re, hashlib
from dataclasses import dataclass
from enum import Enum

class Severity(Enum):
    CRITICAL = "critical"
    HIGH = "high"
    MEDIUM = "medium"

@dataclass
class DetectionResult:
    blocked: bool
    rules_triggered: list[str]
    severity: Severity | None
    sanitized: str

RULES = [
    ("Instruction Override", Severity.CRITICAL,
     re.compile(r"ignore\s+(all\s+)?(previous|prior|above|your)\s+(instructions?|prompts?|system)", re.I)),
    ("Role Hijacking", Severity.HIGH,
     re.compile(r"you\s+are\s+now\s+(a|an|the)\s+\w+", re.I)),
    ("Jailbreak Pattern", Severity.CRITICAL,
     re.compile(r"\b(DAN|do\s+anything\s+now|act\s+as\s+if\s+you\s+have\s+no\s+restrict)", re.I)),
    ("System Prompt Leak", Severity.HIGH,
     re.compile(r"(repeat|reveal|print|show)\s+(your\s+)?(system\s+prompt|instructions?)", re.I)),
    ("Delimiter Injection", Severity.CRITICAL,
     re.compile(r"(<\|im_start\|>|###\s*system|<system>|\[INST\])", re.I)),
    ("Authority Claim", Severity.HIGH,
     re.compile(r"i\s+am\s+(an?\s+)?(admin|developer|anthropic|openai|system)", re.I)),
]

def detect(user_input: str) -> DetectionResult:
    triggered = []
    max_sev = None
    severity_rank = {Severity.CRITICAL: 3, Severity.HIGH: 2, Severity.MEDIUM: 1}

    for name, sev, pattern in RULES:
        if pattern.search(user_input):
            triggered.append(name)
            if max_sev is None or severity_rank[sev] > severity_rank[max_sev]:
                max_sev = sev

    blocked = max_sev in (Severity.CRITICAL, Severity.HIGH)
    sanitized = "[BLOCKED]" if blocked else user_input.strip()

    return DetectionResult(
        blocked=blocked, rules_triggered=triggered,
        severity=max_sev, sanitized=sanitized,
    )

# FastAPI integration
from fastapi import HTTPException

async def guard_input(text: str) -> str:
    result = detect(text)
    if result.blocked:
        raise HTTPException(
            status_code=400,
            detail={"error": "injection_detected", "rules": result.rules_triggered},
        )
    return result.sanitized
# secrets.py — fetch secrets from AWS SSM Parameter Store at runtime
import boto3, os
from functools import lru_cache
from typing import Any

@lru_cache(maxsize=None)
def _ssm():
    return boto3.client("ssm", region_name=os.environ["AWS_REGION"])

def get_secret(param_name: str, decrypt: bool = True) -> str:
    """Fetch a SecureString from SSM. Cached in-process for the container lifetime."""
    response = _ssm().get_parameter(
        Name=param_name, WithDecryption=decrypt
    )
    return response["Parameter"]["Value"]

# ── DETECT HARDCODED SECRETS (pre-commit hook) ──
import re, sys

SECRET_PATTERNS = [
    ("OpenAI Key", re.compile(r'sk-[A-Za-z0-9]{48}')),
    ("AWS Key", re.compile(r'AKIA[A-Z0-9]{16}')),
    ("Hardcoded PW", re.compile(r'password\s*=\s*["\'][^"\']{6,}', re.I)),
    ("JWT Secret", re.compile(r'secret_key\s*=\s*["\'][^"\']{10,}', re.I)),
]

def scan_file(path: str) -> list[dict]:
    findings = []
    with open(path) as f:
        for i, line in enumerate(f, 1):
            for name, pattern in SECRET_PATTERNS:
                if pattern.search(line):
                    findings.append({"rule": name, "line": i, "file": path})
    return findings
# auth_middleware.py — JWT validation with RS256
from fastapi import Depends, HTTPException, Security
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
from jose import jwt, JWTError
import httpx, time
from functools import lru_cache

bearer = HTTPBearer(auto_error=True)

@lru_cache
def _get_jwks() -> dict:
    # Fetch public keys from your auth server (cached)
    resp = httpx.get("https://auth.example.com/.well-known/jwks.json", timeout=5)
    resp.raise_for_status()
    return resp.json()

ALGORITHM = "RS256"
AUDIENCE   = "https://api.example.com"
ISSUER     = "https://auth.example.com"

async def require_auth(
    creds: HTTPAuthorizationCredentials = Security(bearer)
) -> dict:
    token = creds.credentials
    try:
        payload = jwt.decode(
            token,
            _get_jwks(),
            algorithms=[ALGORITHM],
            audience=AUDIENCE,
            issuer=ISSUER,
            options={"verify_exp": True, "verify_iat": True},
        )
    except JWTError as e:
        raise HTTPException(status_code=401, detail=str(e))
    return payload

# Scope enforcement
def require_scope(scope: str):
    async def _check(claims: dict = Depends(require_auth)):
        scopes = claims.get("scope", "").split()
        if scope not in scopes:
            raise HTTPException(status_code=403, detail=f"Scope '{scope}' required")
        return claims
    return _check

# Usage in router
@app.post("/infer")
async def infer(
    body: InferRequest,
    claims: dict = Depends(require_scope("llm:inference")),
):
    return {"user": claims["sub"], "result": ...}
# rate_limiter.py — sliding window token bucket using Redis
import time, redis.asyncio as redis
from fastapi import HTTPException, Request, Depends
from secrets import get_secret

REDIS_URL = get_secret("/ekos/prod/redis-url")
rdb = redis.from_url(REDIS_URL, decode_responses=True)

WINDOW   = 60    # seconds
MAX_REQS = 20    # per window per user
MAX_TOKS = 100_000  # LLM tokens per window

async def rate_limit(request: Request, claims: dict = Depends(require_auth)):
    user_id = claims["sub"]
    now = int(time.time())
    window_key = f"rl:{user_id}:{now // WINDOW}"

    async with rdb.pipeline() as pipe:
        await pipe.incr(window_key)
        await pipe.expire(window_key, WINDOW * 2)
        count, _ = await pipe.execute()

    if count > MAX_REQS:
        raise HTTPException(
            status_code=429,
            detail="Rate limit exceeded",
            headers={"Retry-After": str(WINDOW - (now % WINDOW))},
        )
    return user_id

# Token budget enforcement (LLM-specific)
async def token_budget(user_id: str, tokens_used: int):
    key = f"tokens:{user_id}:{int(time.time()) // WINDOW}"
    async with rdb.pipeline() as pipe:
        await pipe.incrby(key, tokens_used)
        await pipe.expire(key, WINDOW * 2)
        total, _ = await pipe.execute()
    if total > MAX_TOKS:
        raise HTTPException(
            status_code=429,
            detail=f"Token budget exceeded: {total}/{MAX_TOKS} this minute",
        )
# audit_logger.py — structured, immutable audit trail
import structlog, hashlib, time, uuid
from enum import Enum

class AuditEvent(Enum):
    USER_LOGIN        = "user.login"
    PROMPT_SENT       = "llm.prompt.sent"
    SECRET_ACCESSED   = "secret.accessed"
    MODEL_LOADED      = "model.loaded"
    INJECTION_BLOCKED = "security.injection.blocked"
    AUTH_FAILURE      = "auth.failure"

log = structlog.get_logger()

def audit(
    event: AuditEvent,
    user_id: str,
    **kwargs,
) -> None:
    """Write an immutable audit record. Never suppress exceptions here."""
    record = {
        "ts":       time.time(),
        "event":    event.value,
        "user_id":  user_id,
        "trace_id": str(uuid.uuid4()),
        "level":    "AUDIT",
        **kwargs,
    }
    # Hash the record for tamper detection
    record["integrity"] = hashlib.sha256(
        str(sorted(record.items())).encode()
    ).hexdigest()[:16]

    log.info("audit", **record)

# Usage in endpoints
@app.post("/infer")
async def infer(body: InferRequest, user_id: str = Depends(rate_limit)):

        AuditEvent.PROMPT_SENT,
        user_id=user_id,

        model=body.model,
        token_estimate=len(body.prompt.split()) * 1.3,
    )

12.8 · Quick Reference

Security Cheat Sheet

🔴 OWASP Top 3

  • LLM01 Prompt Injection — validate + sanitize all input
  • LLM06 Excessive Agency — least-privilege for every tool call
  • LLM02 Data Leakage — output filter before returning to user
  • LLM03 Supply Chain — hash-verify all models + deps

💉 Injection Defense

  • Layer 1: Regex pattern detection before model sees input
  • Layer 2: Privilege-separated system prompt channel
  • Layer 3: Output scanning for instruction bleed-through
  • Layer 4: Human review for high-risk outputs

🔐 Secrets Ladder

  • Never: Hardcoded in source code
  • Avoid: Committed .env files
  • OK: Runtime env vars + gitignore
  • Best: Vault / SSM at runtime
  • Ideal: IAM short-lived credentials

🔑 Auth Patterns

  • API Key: Simple, stateless — rotate every 90d
  • JWT RS256: Short TTL (15 min), scoped claims
  • OAuth CC: Machine-to-machine, refresh silently
  • Never: HS256 with shared secret in microservices

📝 Audit Logging Rules

  • Always log: Auth events, prompt hashes, model loads
  • Never log: Full prompt text, PII, raw secrets
  • Format: Structured JSON, append-only, with integrity hash
  • Retain: 90 days minimum for SOC 2 / FedRAMP

⛓️ Supply Chain

  • Models: SHA-256 verify before loading
  • Deps: pip-audit + safety in CI, pin versions
  • SBOM: cyclonedx-py — required for DoD
  • Images: Trivy scan in Docker build pipeline
